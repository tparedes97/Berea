# Instrucciones para Claude Code

Trabaja sobre este proyecto y entrega una web elegante que inspire confianza desde el primer momento. Implementa mejoras concretas y comprueba el resultado.

Conserva el logo original de assets/logo.png EXACTAMENTE: no lo redibujes ni cambies las letras. Mantén la imagen tecnológica de portada, el turquesa y azul marino, y todas las fotografías en blanco y negro. Usa las tres imágenes en referencias como guía. Cuida márgenes, tipografía, contraste, imágenes y pequeños detalles; evita íconos grandes, sombras excesivas y decoraciones repetitivas.

El inicio y las seis páginas de servicio deben ser independientes, con URL propia y acceso directo funcional. Las referencias aprobadas cubren inicio, selección y evaluación. Refina las otras cuatro pantallas conservando la coherencia de marca y permite su revisión. No inventes clientes, estadísticas, garantías o certificaciones.

Comprueba responsive, teclado, enlaces, logo, acceso directo y recargas. Integra imágenes de portada sin titulares duplicados. Si mejoras las imágenes, conserva la composición tecnológica que la usuaria eligió. Mantén contenido y controles como HTML real. Añade metadatos sociales por página y favicon con el símbolo original; configura rutas para el hosting elegido. No publiques sin una instrucción de la usuaria.
